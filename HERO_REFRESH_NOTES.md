# Opening sequence notes

The Earth intro retains its existing camera path and color direction, but the cloud treatment is improved with two separate spherical layers: a denser, contrast-rich cloud deck and lighter high-altitude cirrus. A faint inner cloud-shadow pass adds depth. During the final camera zoom, “Welcome to Murali’s Portfolio” appears; the sequence finishes automatically without an Enter Portfolio button.

The WORK/O gateway now opens a full solar-system sequence rather than a single planet or abstract portal. Eight orbiting worlds, orbit paths, Saturn’s rings, an asteroid belt and a star field remain visible while the archive loading HUD moves from handshake to synchronization. The same 3D scene persists until the MuraliOS desktop is ready.

The main site retains the warm ivory / peach / muted-clay / mist-blue / graphite palette, existing project and scroll animations, project art, larger WORK/O hint, certificates and desktop apps.
